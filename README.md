# Calculadora de Extração

App web instalável (PWA) para preparo de café: calcula café, água, moagem e passo a passo para 15 métodos em seis moedores (KINGrinder K7, MHW-3Bomber Blade R3 e R3 Pro, Oster BVSTBMH24, Mongdio HB-991 e iCoffee elétrico).

Funciona sem internet depois da primeira abertura. Para instalar no celular, abra o endereço do GitHub Pages e use "Adicionar à Tela de Início".

Ao atualizar os arquivos, troque o número da versão em `sw.js` (`extracao-vN`) para o celular baixar a nova versão.
